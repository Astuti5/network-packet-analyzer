# PRODIGY_CS_05
🌐 Network Packet Sniffer Simulator🌐  
Using Tkinter, this code creates a Network Packet Sniffer Simulator🌐 that lets users mimic real-time network packet capture.
Users can start and stop the packet capture, view captured packets in a structured format, and see detailed information about each packet 📦.
The application generates random packet data, including protocols, source and destination IPs, and payloads, providing a realistic simulation experience 🎉. A user-friendly interface with buttons and a status bar enhances usability, making it easy to monitor packet activity 📊.
Overall, it serves as an educational tool for understanding network packet structures and behaviors! 🖥️
